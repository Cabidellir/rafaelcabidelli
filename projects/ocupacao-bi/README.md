# Automação de Dados & Business Intelligence — Relatório Histórico de Ocupação

Case study do portfólio de Rafael Cabidelli.

## Visão geral
Solução end-to-end para transformar um report operacional diário numa base histórica e num dashboard de Business Intelligence.

## Fluxo
**ClicknDECiDE / SQL → E-mail → Power Automate → SharePoint → Power BI**

## Tecnologias
- ClicknDECiDE / SQL — extração e preparação
- E-mail — distribuição do report
- Power Automate — automação
- SharePoint — armazenamento histórico
- Power BI — análise e visualização
